The associated header defines FMOD_VERSION 0x00010608 (SDK 1.06.08).

bundled SDK; it is not a runtime version-query result.

Rebuilding and relinking:
The corresponding ShinkiEMU sources bundle retains the exact original Cocos
source archive, external dependency archive and vcpkg overlay recipes/patches
used by this build. DownloadDeps.cmake verifies the external SHA512 above.
Rebuild Cocos and the core with the supplied recipes and headers; reuse the
original prebuilt FMOD input from that verified external archive. Packaging
copies it as the ordinary file libfmod.so.6 and sets a relative $ORIGIN RUNPATH.
The packaged file's hash changes when RUNPATH is written; its input hash above
identifies the original. FMOD implementation source is not in the upstream
archive and is not represented as supplied corresponding source. No generated
or substitute FMOD implementation is included.
